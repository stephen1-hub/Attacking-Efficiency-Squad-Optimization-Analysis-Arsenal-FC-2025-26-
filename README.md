# Attacking-Efficiency-Squad-Optimization-Analysis-Arsenal-FC-2025-26-
# Project Overview

This project analyzes attacking efficiency and squad structure for Arsenal FC using advanced football metrics such as Expected Goals (xG) and Expected Assists (xA).

# Objectives
Evaluate player efficiency
Identify key attacking contributors
Detect under/overperformance
Provide recruitment recommendations
# Key Insights
🔥 Attacking Threat
Max Dowman and Gabriel Jesus show high per-90 attacking output
🎯 Finishing
Eberechi Eze significantly overperforms xG (potential regression)
Viktor Gyökeres shows stable, reliable finishing
🧠 Creativity
Martin Ødegaard is the primary creative hub
Supporting creators include Trossard and Martinelli
# Recommendations
Add a secondary playmaker to reduce reliance on Ødegaard
Improve left-sided attacking consistency
Consider a more clinical striker profile
# Tools Used
Python (Pandas, NumPy, Matplotlib)
Streamlit
Football analytics concepts (xG, xA)
